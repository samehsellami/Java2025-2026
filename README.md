🦁 Zoo Management System

Un mini-projet Java permettant de gérer les animaux d’un zoo, leurs espèces, leur alimentation et leur habitat.

📌 Description du projet

Le Zoo Management System est une application éducative conçue pour apprendre la programmation orientée objet (POO) en Java.
Le projet met en pratique les concepts suivants :

Classes et objets

Héritage

Polymorphisme

Interfaces

Collections

Exceptions
